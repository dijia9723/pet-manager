# deploy_test.go

在可用 POSIX shell 中用临时 id/sudo 替身执行真实提权包装命令，验证 root 直接运行、ubuntu 免密 sudo、sudo 需要密码时明确拒绝，以及脚本仍通过 stdin 传输。诊断测试仅返回已知阶段的提示，不返回远程任意输出或潜在秘密。

通过内存 SFTP 服务的真实协议验证正常隔离根目录、根目录读取权限被拒绝、宿主 /etc/passwd 可见、意外根目录项。复现旧权限错误映射为 20005，并检查初始化验证改为具体的 10503 提示，隔离失败仍拒绝。检查脚本权限约定：公共父目录 0711、root 所有的站点根目录 0755、站点账号所有的 www 0750。
