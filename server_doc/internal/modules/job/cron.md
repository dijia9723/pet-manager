# internal/modules/job/cron.go — 轻量 cron 解析器

> 脚手架导航：[回到开发者入口](../../../../README.md) · [service.md](service.md) · [cron_test.md](cron_test.md)

5 段 cron（分 时 日 月 周）的自实现解析器，**不引入第三方调度库**：底座只需要分钟级周期调度与可校验的表达式，约一百行即可覆盖常用写法，便于审计与离线部署。

## 支持的写法

每段支持：`*`、`*/n`、单值 `a`、区间 `a-b`、列表 `a,b,c`，以及它们与步长的组合（`a-b/n`、`a/n`）。

| 段 | 区间 | 备注 |
| --- | --- | --- |
| 分 | 0-59 | |
| 时 | 0-23 | |
| 日 | 1-31 | |
| 月 | 1-12 | |
| 周 | 0-7 | 0 与 7 同为周日，内部归一化为 0 |

示例：`30 3 * * *`（每日 03:30）、`*/15 * * * *`（每 15 分钟）、`0 9 * * 1-5`（工作日 09:00）。

## 关键类型与函数

- `parseCron(expr string) (*cronSchedule, error)`：解析并逐段报错（`cron 第 n 段 "x" 非法: 原因`），handler 直接包成 400 返回；
- `cronSchedule.next(after time.Time) time.Time`：返回 **严格晚于** after 的下一个整分钟（秒清零），按进程本地时区计算（与 GORM `NowFunc` 的 `time.Local` 一致）；
  - 实现为逐分钟扫描，上限 5 年（覆盖闰年周期），超期未命中（如 2 月 31 日）返回零值时间，调度器据此清空 `next_run_at`。

## 语义细节

- 日、周两段同时被显式限制（都不是 `*`）时按**标准 cron 的 OR 语义**：任一满足即触发；
- `* / 步长` 与单值带步长（`5/10`）按"从该值到上界"展开；
- 边界与语义由 [cron_test.md](cron_test.md) 中的单测锁定（每日定点、步长、工作日区间、周日归一化、月/日、严格晚于）。
