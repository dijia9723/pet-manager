# 任务管理（增删改）

> [开发者入口](../../../../README.md) · [任务管理](service.md) · [HTTP 接口](handler.md) · [执行锁](lock.md) · [模型](../../model/job.md)

## 职责

负责任务的创建、修改、删除与配置归一化，是任务 CRUD 的落库入口。

## 关键类型与函数

| 符号 | 说明 |
| --- | --- |
| `CreateInput` | 新建任务入参（`Code`/`Kind`/`Spec` 为核心字段） |
| `definition` | 校验并归一化为可落库任务行：默认停用、默认超时 60s；启用时预计算 `NextRunAt`（cron 无有效命中则报错） |
| `Create` | 新建自定义任务；占用内置方法保留的编码时直接拒绝 |
| `updateDefinition` | 行锁保护下修改定义，改后重走 `definition` 并重算下次执行时间 |
| `Delete` | 删除自定义任务，要求已停用且不在执行中 |
| `writeError` | 归一化数据库错误：业务错误原样返回，唯一键冲突转“编码已存在”，其余包装为库错误 |

## 约定与坑

- **预置（builtin）任务限制**：只能修改调度（`spec`）、超时和说明，禁止改名称/类型/执行方法，且禁止删除。
- **删除的并发安全**：先做进程内 `running` 标记，再抢执行锁；随后在**事务内二次校验**状态与执行身份（`identity`），避免删除与并发执行/改配置竞态。
- 编码唯一冲突通过 `gorm.ErrDuplicatedKey` 或 PostgreSQL `23505` 识别。
- 超时取值 1–600 秒；`Spec` ≤64 位，名称 ≤128 字，说明 ≤255 字。
