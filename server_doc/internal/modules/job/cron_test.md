# internal/modules/job/cron_test.go

> 脚手架导航：[回到开发者入口](../../../../README.md) · [cron.md](cron.md)

cron 解析器的表驱动单测，不依赖外部服务，随 `go test ./internal/...` 运行。

覆盖范围：

- 非法表达式：段数不对、越界（`60` 分、`24` 时、`0-60`）、零步长、非数字；
- 合法形态：每日定点（`30 3 * * *`）、步长（`*/15`）、周（`1`=周一）、周日 7/0 归一化、每月某日、列表+区间（`30 9,18 * * 1-5`）；
- `next` 必须返回**严格晚于**入参的整分钟（命中当前分钟时顺延一个周期）；
- 用例中的星期断言基于真实日历（2026-10-09 为周五），同时锁定时区按 `time.Local` 计算。
